# android-security

Açık kaynaklı Android güvenlik tarayıcısı ile telefonunuzu baştan aşağı analiz edin. Termux üzerinde çalışır, tamamen ücretsiz ve açık kaynak.

🔍 ARAÇ NELERİ TARIYOR?

✅ Root / Magisk kontrolü

✅ Zararlı yazılım & casus yazılım (spyware) veritabanı

✅ Uygulama izinleri ve risk skoru

✅ Şüpheli ağ bağlantıları ve portlar

✅ Erişilebilirlik servisleri (casus yazılım kontrolü)

✅ Cihaz yöneticisi analizi

✅ Gizli APK ve dosya taraması

✅ Pil sıcaklığı & performans kontrolü

✅ Güvenlik ayarları denetimi

⚙️ KURULUM

1. Termux'u indirin (F-Droid önerilir)

2. pkg install python -y

3. python3 codza_security_scanner.py
